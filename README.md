# 🏋️ Online Fitness Class Booking - Frontend

A React-based frontend application for an Online Fitness Class Booking Platform.

Users can browse fitness classes, view trainers, book classes, make dummy payments, give feedback, and manage their bookings.

The application also includes separate dashboards for:

- 👤 User
- 🧑‍🏫 Trainer
- 👨‍💼 Admin

---

## 🚀 Features

### 👤 User

- User Registration
- User Login
- Browse Fitness Classes
- View Class Details
- View Trainer Profiles
- Book Fitness Classes
- Select Available Time Slots
- Dummy Payment Flow
- View My Bookings
- View Booking Details
- Give Trainer Feedback
- Give Class Feedback
- Manage User Profile
- User Dashboard

### 🧑‍🏫 Trainer

- Trainer Login
- Trainer Dashboard
- View Total Students
- View Total Classes
- View Total Bookings
- View Today's Sessions
- View Trainer Rating
- Manage Trainer Profile
- Upload Profile Image
- Add Class Schedule
- Delete Schedule
- View Bookings
- View Students
- View Reviews
- Online Meeting Link

### 👨‍💼 Admin

- Admin Login
- Admin Dashboard
- Total Users
- Total Trainers
- Total Classes
- Total Bookings
- Total Revenue
- Paid Bookings
- Total Feedback
- Today's Bookings
- View Users
- View Trainers
- View Classes
- View Bookings
- Manage Trainers
- Manage Classes
